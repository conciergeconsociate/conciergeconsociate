# Consociate Concierge

Premium concierge services tailored to your lifestyle.

## Project Overview

This project is a React-based web application for Consociate Concierge, offering luxury lifestyle management, travel planning, event coordination, and more.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Supabase (Database, Auth, Edge Functions)
- **UI Components:** Shadcn UI, Lucide React

## Features

- **Service Management:** Explore and book various concierge services.
- **Membership:** Exclusive membership plans and benefits.
- **Venue Booking:** Discover and book featured venues.
- **Blog:** Latest news and lifestyle articles.
- **Admin Panel:** Comprehensive dashboard for managing users, bookings, services, and content.

## Getting Started

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Run Development Server:**
    ```bash
    npm run dev
    ```

3.  **Build for Production:**
    ```bash
    npm run build
    ```

## Environment Variables

Create a `.env` file with the following:

```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
